Instagram-Pakete

Diese Seite baut sich aus den Projekten der Homepage. Titelkachel, Bilder im Format 4:5 und ein Textvorschlag. Sie ist nirgends verlinkt.

  1. Auf dem iPhone jedes Bild lange drücken → «In Fotos sichern». Video: lange drücken oder öffnen → Teilen → «Video sichern».
  2. Instagram → + → Beitrag → Bilder in der Reihenfolge wählen, Format 4:5.
  3. Text anpassen, kopieren, einfügen, teilen.
  4. Link zum Beitrag im Admin beim Projekt unter «Instagram-Beitrag» eintragen.
